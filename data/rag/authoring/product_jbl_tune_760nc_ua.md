# Навушники JBL Tune 760NC — сторінка товару

Ціна: 3 299 грн. Оновлено: 01.07.2025.

## Коротко

Повнорозмірні бездротові навушники з активним шумозаглушенням (ANC), складна конструкція, підключення до двох пристроїв одночасно (Multi-Point).

## Характеристики

| Параметр | Значення |
|---|---|
| тип | повнорозмірні (over-ear) |
| Bluetooth | 5.0 |
| LE Audio | не підтримується |
| шумозаглушення | активне (ANC), не адаптивне |
| робота з ANC | до 35 год |
| робота без ANC | до 50 год |
| швидка зарядка | 5 хв = 2 год музики |
| повна зарядка | менше 2 год |
| вага | 220 г |
| дріт 3,5 мм | так, у комплекті |

## Комплектація

Навушники, кабель USB-C для заряджання, знімний аудіокабель, документація.

## Гарантія та повернення

Гарантія 12 місяців. Ремонт виконується лише через ElectroStore. Повнорозмірні навушники можна повернути протягом строку повернення, якщо збережено товарний вигляд.

## Не плутайте з моделлю 770NC

JBL Tune 770NC — новіша модель з адаптивним шумозаглушенням, Bluetooth 5.3 і довшим часом роботи.
